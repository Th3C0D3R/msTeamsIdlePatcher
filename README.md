# MSTeams Idle Patcher script. 

It lets you patch out the automation setting you to "Away" if you dont do any Inputs (Keyboard/Mouse). 

It is not update-resilient so you have to either never update or run the script again after each update. 

You could also run it on startup as it patches the JS-layer

### Supported Versions:
Testes with:
- 26246.1604.5133.838
- 26260.1717.5229.7049
